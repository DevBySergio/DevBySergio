## Featured Projects

### 🗂️ [Lynvo](https://github.com/DevBySergio/Lynvo_by_Sergio)

**A local-first project management system built directly into VS Code.**

Lynvo turns the editor into a development-oriented Kanban workspace where tasks can be connected directly to source code.

Beyond the board itself, the project explores some ideas I'm particularly interested in:

* Local-first architecture with project data stored as inspectable files
* Git-based team synchronization without requiring an application backend
* Field-level conflict detection and resolution
* Tasks linked directly to files and source-code ranges
* Project analytics, activity tracking and dependency relationships
* Integration with AI coding agents such as Claude Code, Cline, Cursor and OpenCode
* Agent-accessible project state so AI tools can create, update and complete development tasks as they work

The goal is to make project management part of the engineering environment itself rather than another external tool developers have to constantly switch to.

### ⚡ [JustAPI](https://github.com/DevBySergio/JustAPI_by_Sergio)

**A local-first HTTP client for VS Code focused on privacy, reliability and developer workflows.**

JustAPI lets developers create, organize and execute HTTP requests without accounts, telemetry or cloud synchronization.

The project goes beyond sending HTTP requests and includes:

* HTTP/HTTPS request execution with redirects, TLS options, compression and detailed timings
* Collections, environments and variable resolution
* Bearer, Basic and API-key authentication
* Credential storage through VS Code `SecretStorage`
* Safe cURL parsing without executing shell commands
* Code generation for TypeScript, JavaScript, Python, C#, Java, Go and cURL
* Versioned local storage with atomic writes and verified backups
* Migration and corruption-recovery mechanisms
* Redaction of credentials from history, exports and generated code
* Unit, integration and real VS Code extension-host testing

JustAPI reflects the kind of software I enjoy building: **developer-facing products where architecture, security and reliability matter as much as the interface itself.**
